## <img src="https://raw.githubusercontent.com/rosgear/rg-be-mp-themes/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Расширение модуля «Темы оформления»

Темы оформления предоставляют возможность кастомизации внешнего вида сайта и Панели управления GePanel: допускается установка новых шаблонов, удаление неактуальных и замена текущих вариантов.

Расширение модуля входит в состав Панели управления GePanel и cлужит расширением для [модуля «Маркетплейс приложений»](https://github.com/rosgear/rg-be-mp).

### Скриншот
<img src="https://github.com/rosgear/rg-be-mp-themes/blob/main/assets/help/grid.png?raw=true">

### Установка

Для добавления расширения модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-mp-themes
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-mp-themes": "*"
}
```
или скачать архив на [странице расширения модуля](https://rosgear.ru/component/rg-be-mp-themes/) в каталоге приложений RosGear.

После добавления расширения модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

<a name="english"></a>
## <img src="https://raw.githubusercontent.com/rosgear/rg-be-mp-themes/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module extension «Themes»

Themes allow you to customize the appearance of your website and the GePanel Control Panel: you can install new templates, remove outdated ones, and replace existing ones.

The module extension is part of the GePanel Control Panel and serves as an extension for the [«Application Marketplace» module](https://github.com/rosgear/rg-be-mp).

### Screenshot
<img src="https://github.com/rosgear/rg-be-mp-themes/blob/main/assets/help/grid.png?raw=true">

### Installation

To add the module extension to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-mp-themes
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-mp-themes": "*"
}
```
or download the archive from the [module extension page](https://rosgear.ru/component/rg-be-mp-themes/) in the RosGear application catalog.

After adding the module extension to the project, install it into the web application edition using the GePanel Control Panel.
